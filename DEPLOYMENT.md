# 🚀 Vercel Deployment & GitHub OAuth Setup Guide

This guide walks you through deploying **CapStoneFlow** to Vercel with serverless GitHub OAuth 2.0 authentication and automated CI/CD.

---

## 1. ⚙️ GitHub OAuth 2.0 App Configuration

1. Go to your GitHub Developer Settings:  
   👉 **[GitHub Developer Settings ➔ OAuth Apps](https://github.com/settings/developers)**
2. Click **New OAuth App** (or edit your existing app).
3. Fill in the application details:
   - **Application Name**: `CapStoneFlow` (or your project name)
   - **Homepage URL**:  
     `https://<your-project-name>.vercel.app` (or `http://localhost:5173` for local testing)
   - **Authorization callback URL**:  
     `https://<your-project-name>.vercel.app/` (or `http://localhost:5173/` for local testing)
4. Click **Register Application**.
5. Copy your **Client ID** (`VITE_GITHUB_CLIENT_ID`).
6. Click **Generate a new client secret** and copy your **Client Secret** (`GITHUB_CLIENT_SECRET`).

> [!TIP]
> **Pro Tip**: If you want OAuth to work seamlessly on **both** localhost and Vercel simultaneously without changing URLs back and forth, create **two** OAuth apps on GitHub:
> 1. `CapStoneFlow (Local Dev)`: Callback `http://localhost:5173/`
> 2. `CapStoneFlow (Production)`: Callback `https://<your-project-name>.vercel.app/`

## 2. 🌐 Vercel Deployment Options

### Option A: Deploy with Vercel CLI (Fastest)

1. Open your terminal in `f:/Capstone`:
```bash
# 1. Install Vercel CLI (if not already installed)
npm install -g vercel

# 2. Login to Vercel
vercel login

# 3. Deploy project
vercel
```

2. Follow the prompts:
   - Set up and deploy `f:/Capstone`? `Y`
   - Which scope? (Select your personal account or team)
   - Link to existing project? `N`
   - Project name? `capstone-flow` (or your choice)
   - In which directory is your code located? `./`
   - Want to modify build settings? `N` (Vercel automatically detects Vite + `vercel.json`)

---

### Option B: Deploy via GitHub Repository Import

1. Push your repository to GitHub:
```bash
git add .
git commit -m "feat: configure Vercel deployment and serverless OAuth proxy"
git push origin main
```
2. Go to **[vercel.com/new](https://vercel.com/new)** and import your GitHub repository.
3. In the **Configure Project** screen, add the Environment Variables (see Section 3 below).
4. Click **Deploy**.

---

## 3. 🔑 Environment Variables on Vercel Dashboard

In your Vercel Project Settings:  
👉 **Project Settings ➔ Environment Variables**

Add the following 2 variables:

| Variable Name | Value | Target Environment |
| :--- | :--- | :--- |
| **`VITE_GITHUB_CLIENT_ID`** | `Ov23li...` (Your GitHub OAuth Client ID) | `Production`, `Preview`, `Development` |
| **`GITHUB_CLIENT_SECRET`** | `10dc12...` (Your GitHub OAuth Client Secret) | `Production`, `Preview`, `Development` |

*(Optional)* If using a custom domain or specific callback path:
- `VITE_GITHUB_REDIRECT_URI`: `https://your-custom-domain.com/`

## 4. 📁 Architecture on Vercel

```
Capstone/
├── api/
│   └── auth/
│       └── github.js      <-- Vercel Serverless Function: securely exchanges OAuth code with GitHub API
├── dist/                  <-- Production SPA build generated by Vite
├── src/                   <-- React + TypeScript client source
├── vercel.json            <-- Configures SPA fallback routing & /api/ rewrites
├── .env.example           <-- Environment variable template
└── package.json           <-- Build scripts & dependencies
```
